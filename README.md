# Video Prompt Director

짧은 아이디어를 장면 구성과 레퍼런스 이미지 계획으로 발전시킨 뒤, AI 영상 생성기에 바로 넣을 프롬프트로 정리하는 Aside 스킬입니다. 카메라·렌즈 용어를 몰라도 평소 말투로 요청할 수 있습니다.

## 무엇을 해주나요?

- 이야기의 핵심을 보존하면서 장면 수와 흐름을 구성합니다.
- 각 장면에서 보이는 대상, 행동, 카메라 움직임, 초점, 빛과 분위기를 필요한 만큼 정합니다.
- 레퍼런스 이미지가 **불필요한지, 있으면 좋은지, 권장되는지** 판단하고 어떤 이미지가 유용한지 설명합니다.
- 대상 영상 생성기에 맞춘 프롬프트를 작성합니다. Kling을 지정하면 기본적으로 한국어 설명과 영어 생성용 프롬프트를 제공합니다.
- 이미 생성한 영상의 문제를 듣고, 마음에 든 부분은 유지하면서 필요한 지시만 고칩니다.

## 설치

### Aside에서 사용하기

`SKILL.md`를 Aside 계정의 사용자 스킬 폴더에 다음 구조로 복사합니다.

```text
skills/user/video-prompt-director/SKILL.md
```

폴더가 없다면 `video-prompt-director` 폴더를 만들면 됩니다. Aside가 사용자 스킬을 불러오면, 짧은 영상 아이디어를 프롬프트로 바꾸거나 레퍼런스를 계획해 달라고 요청할 때 활용할 수 있습니다.

### 다른 AI에서 사용하기

다른 AI 도구에서는 `SKILL.md`의 본문을 프로젝트 지침이나 사용자 지정 지침에 붙여넣어 비슷한 작업 방식으로 사용할 수 있습니다. 자동 활성화 방식은 각 도구마다 다릅니다.

## 빠르게 시작하기

전문 용어나 정해진 양식은 필요하지 않습니다. 한 문장으로 시작하고, 이미 알고 있는 조건만 덧붙이세요.

> 비 내리는 새벽 항구에서 낡은 어선을 바라보는 10초 영상. 조용하고 쓸쓸하게. 배의 외형은 장면이 바뀌어도 같게 해줘. 레퍼런스가 필요한지도 알려줘.

원한다면 다음 정보도 보탤 수 있습니다.

- 꼭 보여야 할 대상이나 사건
- 원하는 분위기 또는 참고하고 싶은 작품의 느낌
- 길이와 화면 비율
- 같은 모양으로 유지할 인물·장소·물건
- 화면에 나오면 안 되는 것

모르는 항목은 비워도 됩니다. 스킬은 핵심을 바꾸는 중요한 모호함이 있을 때만 짧게 질문하고, 나머지는 보수적으로 판단해 가정을 알려줍니다.

## 레퍼런스 이미지는 언제 쓰나요?

| 판단 | 쓰기 좋은 경우 | 예시 |
| --- | --- | --- |
| 불필요 | 특정한 외형을 고정할 필요가 없는 일반적인 장면 | 안개, 파도, 비 내리는 거리 |
| 있으면 도움 | 화면의 색감이나 분위기를 더 정확히 잡고 싶을 때 | 차가운 새벽빛, 따뜻한 빈티지 톤 |
| 권장 | 같은 인물·제품·배·장소의 모양을 반복 장면에서 유지해야 할 때 | 여러 컷에 등장하는 특정 어선 |

레퍼런스는 목적에 맞게 골라야 합니다. 인물·물건의 외형을 보여주는 이미지, 영상의 첫 구도를 정하는 이미지, 색감만 참고하는 이미지는 서로 역할이 다릅니다. AI는 필요한 이미지의 종류와 별도 이미지 생성용 문구를 제안할 수 있지만, 특정 실존 인물·장소·제품의 모양이 정확해야 한다면 사용자가 원본을 제공하거나 승인해야 합니다.

생성기에 이미지를 넣지 않았다면 프롬프트에 “참고 이미지와 같은 배”라고만 써도 모델은 그 이미지를 알 수 없습니다. 이 경우에는 실제 이미지를 첨부하거나, 배의 외형을 글로 설명해야 합니다. 여러 장면을 한 번에 정확히 제어하기 어려운 생성기라면 장면을 따로 생성해 편집하는 방법을 제안할 수 있습니다.

## 결과를 고쳐나가는 방법

결과에서 아쉬운 점을 평소 말투로 알려주세요. 촬영 용어를 몰라도 됩니다.

> 분위기와 색감은 좋아. 카메라 흔들림만 줄이고 나머지는 유지해줘.

> 배는 잘 나왔는데 사람이 추가됐어. 인물 없이 배와 바다만 나오도록 고쳐줘.

스킬은 성공한 요소를 유지하고 해당 문제와 관련된 지시만 수정하도록 설계되어 있습니다.

## 작성 원칙과 한계

- 사용자가 말하지 않은 인물·사건·소품을 임의로 추가하지 않습니다.
- 매번 같은 영화 효과를 복사하지 않고, 이야기의 내용에 맞춰 색감과 카메라 연출을 고릅니다.
- 장면마다 핵심 행동을 분명히 하고, 서로 모순되거나 중복되는 지시는 줄입니다.
- 레퍼런스를 무조건 요구하지 않습니다.
- 프롬프트는 생성 결과를 안내할 뿐, 영상 생성 모델의 동작을 완전히 보장하지는 않습니다. 결과를 확인하고 한두 가지씩 수정하는 과정이 필요합니다.
